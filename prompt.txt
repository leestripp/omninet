Here are ideas for built-in admin endpoints under `/omninet/*`:

---

## `/omninet/health`
- **GET** - Basic health check (returns status, uptime, version)
- Returns: `{ "status": "ok", "uptime": 3600, "version": "0.1.0" }`

## `/omninet/status`
- **GET** - Detailed server status
- Returns: `{ "requests": {...}, "connections": {...}, "memory": {...}, "threads": {...} }`

## `/omninet/stats`
- **GET** - Real-time statistics
- Returns: `{ "requestsTotal": N, "requestsActive": N, "bytesIn": N, "bytesOut": N, ... }`

## `/omninet/users`
- **GET** - List all users
- **POST** - Create user
- **DELETE** `/omninet/users/:username` - Delete user

## `/omninet/sessions`
- **GET** - List active sessions
- **DELETE** `/omninet/sessions/:id` - Revoke session
- **DELETE** `/omninet/sessions/user/:username` - Revoke all sessions for user

## `/omninet/firewall/blocked`
- **GET** - List blocked IPs
- **POST** - Block an IP (body: `{ "ip": "...", "duration": "30m" }`)
- **DELETE** `/omninet/firewall/blocked/:ip` - Unblock IP
- **DELETE** `/omninet/firewall/blocked` - Unblock all

## `/omninet/firewall/logs`
- **GET** - Intrusion detection logs
- Query params: `?limit=50&since=timestamp`

## `/omninet/logs`
- **GET** - Server log entries
- Query params: `?level=ERROR&grep=keyword&lines=50&since=timestamp`

## `/omninet/config`
- **GET** - Current configuration (sanitized, no secrets)
- **PUT** - Update configuration (partial update)

## `/omninet/server`
- **GET** - Server info
- **POST** `/omninet/server/restart` - Graceful restart
- **POST** `/omninet/server/stop` - Graceful shutdown

## `/omninet/db`
- **GET** - Database stats (size, tables, row counts)
- **POST** `/omninet/db/backup` - Trigger backup
- **POST** `/omninet/db/vacuum` - Optimize database

## `/omninet/certs`
- **GET** - List certificates
- **GET** `/omninet/certs/:name` - Certificate details
- **POST** `/omninet/certs/check` - Check expiry dates

## `/omninet/metrics`
- **GET** - Prometheus-style metrics endpoint
- Returns: `{ "requests_total": N, "response_time_ms": {...}, "connections_active": N }`

---

## Authentication Ideas

These endpoints should probably require:
1. **Admin session/token** - Check for valid admin session cookie or `Authorization: Bearer <token>`
2. **IP whitelist** - Only allow from localhost or whitelisted IPs
3. **Rate limiting bypass** - Admins get higher limits
