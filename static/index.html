Welcome to OmniNet

A lightweight, modular C++20 HTTP/WebSocket server library with TLS support, session management, and optional admin dashboard.

C++20 Modern C++
TLS SSL/TLS Support
WS WebSocket
SQL SQLite3

Features

  • ✓ High-performance HTTP/1.1 server with keep-alive support
  • ✓ Full WebSocket support (RFC 6455)
  • ✓ TLS/SSL encryption with OpenSSL
  • ✓ Session management with SQLite
  • ✓ User authentication and RBAC
  • ✓ Server-Sent Events (SSE)
  • ✓ Intrusion detection (SQL injection, XSS, path traversal)
  • ✓ Static file serving with MIME types

API Endpoints

Method Path Description

Quick Start

#include "OmniNet.h"

using namespace OmniNet;

int main() {
    OmniNet::init();
    
    HTTP::Server server;
    server.get("/hello", [](const HTTP::Request& req, HTTP::Response& resp) {
        resp.setBody("Hello, World!");
    });
    
    server.start();
    std::this_thread::sleep_for(std::chrono::hours(24));
    server.stop();
    
    OmniNet::cleanup();
    return 0;
}

WebSocket Demo

Test WebSocket functionality in your browser console:

// Connect to echo endpoint
const ws = new WebSocket('ws://localhost:8080/echo');

ws.onopen = () => {
    console.log('Connected!');
    ws.send('Hello, OmniNet!');
};

ws.onmessage = (event) => {
    console.log('Received:', event.data);
};
