# Migration Guide: v0.9.0 → v0.10.0

OmniNet v0.10.0 adopts the [Freedesktop XDG Base Directory Specification](../xdg-standard.md) for where user-specific files are stored.

## What's Changed

On a fresh Linux/Unix install, OmniNet now stores files under the standard XDG directories instead of a single `~/.omninet/` tree:

| File / Kind | Old location | New location |
|-------------|--------------|--------------|
| Config | `~/.omninet/config.json` | `$XDG_CONFIG_HOME/omninet/config.json` (default `~/.config/omninet/config.json`) |
| Database | `~/.omninet/omninet.db` | `$XDG_DATA_HOME/omninet/omninet.db` (default `~/.local/share/omninet/omninet.db`) |
| TLS certificates | `~/.omninet/certs/` | `$XDG_DATA_HOME/omninet/certs/` |
| Server configs | `~/.omninet/servers/` | `$XDG_DATA_HOME/omninet/servers/` |
| Logs | `~/.omninet/omninet.log` | `$XDG_STATE_HOME/omninet/omninet.log` (default `~/.local/state/omninet/omninet.log`) |
| Cache | `~/.omninet/` (unused) | `$XDG_CACHE_HOME/omninet/` |
| Runtime / PID files | `~/.omninet/*.pid` | `$XDG_RUNTIME_DIR/omninet/*.pid` |

## Backward Compatibility

v0.10.0 is **backward-compatible**:

- If `~/.omninet/` already exists, OmniNet continues to use it (legacy mode).
- If `OMNINET_DATA_DIR` is set, OmniNet uses that directory as the single-tree root (legacy override).
- Existing code that calls `Config::instance().dataDir()` continues to return the correct data directory.

## Migrating an Existing Installation

Run the migration command:

```bash
./build/tools/omninet-init --migrate-xdg
```

This will:

1. Create the XDG directories.
2. Move `~/.omninet/config.json` → `$XDG_CONFIG_HOME/omninet/config.json`.
3. Move `~/.omninet/omninet.db`, `certs/`, `servers/` → `$XDG_DATA_HOME/omninet/`.
4. Move `~/.omninet/omninet.log*` → `$XDG_STATE_HOME/omninet/`.
5. Move `~/.omninet/*.pid` → `$XDG_RUNTIME_DIR/omninet/`.
6. Rename `~/.omninet/` to `~/.omninet.bak/`.

After migration, stop any running OmniNet servers and start them again so they pick up the new paths.

## API Changes

### `Config`

New methods were added to query the XDG directories:

```cpp
auto& cfg = OmniNet::Config::instance();

cfg.configDir();   // $XDG_CONFIG_HOME/omninet
cfg.dataDir();     // $XDG_DATA_HOME/omninet  (unchanged semantic meaning)
cfg.stateDir();    // $XDG_STATE_HOME/omninet
cfg.cacheDir();    // $XDG_CACHE_HOME/omninet
cfg.runtimeDir();  // $XDG_RUNTIME_DIR/omninet
cfg.configFile();  // configDir() / "config.json"
```

`Config::dataDir()` still returns the directory used for data files (database, certificates, server configs). Under XDG this is `$XDG_DATA_HOME/omninet`; under legacy mode it is `~/.omninet`.

### `OmniNet::Tools::Paths`

The CLI tools use the same effective paths:

```cpp
OmniNet::Tools::Paths::configDir();
OmniNet::Tools::Paths::dataDir();
OmniNet::Tools::Paths::stateDir();
OmniNet::Tools::Paths::cacheDir();
OmniNet::Tools::Paths::runtimeDir();
OmniNet::Tools::Paths::configFile();
OmniNet::Tools::Paths::logFile();      // stateDir() / "omninet.log"
OmniNet::Tools::Paths::databaseFile(); // dataDir() / "omninet.db"
OmniNet::Tools::Paths::certsDir();     // dataDir() / "certs"
OmniNet::Tools::Paths::serversDir();   // dataDir() / "servers"
```

### Logging

Relative log file paths in `LoggingConfig` are now resolved against `Config::stateDir()` instead of `Config::dataDir()`. Update any hard-coded log paths accordingly:

```cpp
LoggingConfig logConfig;
logConfig.file = "omninet.log";  // Resolved to stateDir() / "omninet.log"
```

## Environment Variables

OmniNet now reads the standard XDG variables:

| Variable | Purpose |
|----------|---------|
| `XDG_CONFIG_HOME` | Base directory for config files |
| `XDG_DATA_HOME` | Base directory for data files |
| `XDG_STATE_HOME` | Base directory for state files (logs) |
| `XDG_CACHE_HOME` | Base directory for cache files |
| `XDG_RUNTIME_DIR` | Base directory for runtime files (PID files, sockets) |

The legacy override is still supported:

| Variable | Purpose |
|----------|---------|
| `OMNINET_DATA_DIR` | Forces the legacy single-tree layout |
